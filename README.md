# Carta Digital El Pollón

Pantalla de presentación estática con **HTML, CSS y JavaScript** (sin React).

## Pantalla actual

- Título **CARTA DIGITAL**
- Logo El Pollón
- Carrusel 3D circular con fotos de platos (giro infinito)
- Botón **INGRESAR** → [el-pollon.cl](https://www.el-pollon.cl)

## Ver en local

```bash
npx serve .
```

Abre: http://localhost:3000

O abre `index.html` directamente en el navegador.

## Archivos

```
index.html
css/style.css
js/app.js
assets/logo-pollon.png
```

## Personalizar

- **Logo:** reemplaza `assets/logo-pollon.png`
- **Platos del carrusel:** edita el array `DISHES` en `js/app.js`
- **Link del botón:** cambia el `href` en `index.html`
